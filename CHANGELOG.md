# Changelog

## 0.2.0 — Phase 2 + Phase 3

### Added
- Active-window screenshots via `grim` geometry
- Stronger project detection (more markers, scoring, file-title hints)
- Session list / stop / reuse in panel + `hyprgrok sessions`
- Prompt history (`hyprgrok history`) with panel History tab
- **Ask about current window** (`hyprgrok ask-window`, Super+Ctrl+G)
- Waybar module: `hyprgrok status --waybar` + config snippet
- Hyprland helpers: `hyprgrok hypr snapshot|clients|dispatch|reload`
- Grok-missing banner and richer error UX in the panel
- Panel tabs, slide-in animation, theme polish
- ACP future notes, Waybar docs, MCP example stub

### Changed
- Version bump to 0.2.0
- Installer binds use absolute path + ask-window keybind

## 0.1.0 — MVP
